# Website

Next.js/Fumadocs static export to GitHub Pages, separate from Cargo.
Run commands from `website/` with pnpm:

- `pnpm dev` starts development; `pnpm build` produces the static export.
- `pnpm lint` and `pnpm types:check` check source and generated MDX/Next types.

Keep `content/` aligned with supported CLI behavior.
`public/extensions/catalog.json` is generated by the extension release
workflow; never hand-edit its versions, asset URLs, or SHA-256 checksums.
